Unique Selling Point (25% Weight)

Dynamic Crowd-Escalation Priority Algorithm

Instead of 20 duplicate emails, affected students tap +1 Confirm Broken.

Priority Score = BaseWeight + (3.5 × Confirmations) + (1.2 × HoursPending)
Automated Urgency Surge As more students confirm an outage, the incident automatically leaps to CRITICAL on the estate dashboard without human triage delays.
Crowd-Verified Fixes Students tap "Report Working" once an appliance is repaired, closing the feedback loop and preventing phantom resolutions.
Technical Implementation (20% Weight)

Fast, Lightweight & Robust Tech Stack

Backend & Engine

  • • FastAPI (Python 3.11): Sub-10ms response latency, async IO.
  • • SQLAlchemy 2.0 ORM: Strict relational schema for Hostels, Appliances, Tickets, and Votes.
  • • SQLite Database: Zero external configuration, instant judge evaluation.

Frontend & Client

  • • Tailwind CSS + Glassmorphism: Modern dark-mode mobile UI.
  • • Zero NPM / Build Overhead: Served directly by FastAPI; judges run one command and it works.
  • • Optimistic UI Updates: Real-time confirmation feedback.
