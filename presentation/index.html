Unique Selling Point (25% Weight)

Dynamic Crowd-Escalation & Consensus Engine

Instead of 20 duplicate emails, affected students tap +1 Confirm Broken.

Priority Score = BaseWeight + (3.5 × Confirmations) + (1.2 × HoursPending)
1. Automated Urgency Surge As more students confirm an outage, priority automatically surges from Low to CRITICAL, instantly alerting the estate dispatch queue without human delay.
2. Multi-Resident Consensus Fixes cannot be cleared by an accidental single click. Restoring an appliance requires a 2-student verification quorum with token deduplication.
3. 2-Step Sign-Off & SMS Technician completion (Step 1) triggers an automated resident SMS alert; room complaints only close upon student digital verification (Step 2).
Technical Implementation (20% Weight)

Unified Single-Port Architecture

Backend & Engine

  • • FastAPI (Python 3.11): Sub-10ms response latency, async IO, 179.5 req/sec proven load capacity.
  • • Unified Micro-Portals on Port 8000: Single-port routing for Student (`/`), Tech (`/tech`), and Admin (`/admin`).
  • • SQLite WAL Mode: High-concurrency lock-free reads and writes across simultaneous multi-portal sessions.
  • • Defense-in-Depth Security: Rate-limiting buckets, session HMACs with 24h sliding TTL, input phone sanitization.

Frontend & Client

  • • Tailwind CSS + Glassmorphism: Responsive dark-mode and light-mode consoles.
  • • Zero NPM / Build Overhead: Served directly by FastAPI; judges run `./start.sh` and it executes instantly.
  • • Non-Intrusive Floating Toasts: Real-time feedback for consensus updates and 1-click lookups.
  • • Interactive OpenAPI / Swagger: Complete interactive API testing suite live at `/docs`.
